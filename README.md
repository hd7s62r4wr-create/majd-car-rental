# مجد لتأجير السيارات | MAJD RENT A CAR

تطبيق عربي لمشاركة الموقع المباشر بموافقة صاحبه، مع لوحة متابعة خاصة بالمالك.

## التشغيل
- Node.js 18 أو أحدث
- `npm install`
- ضبط متغير البيئة `OWNER_TOKEN` بقيمة عشوائية سرية لا تقل عن 32 حرفاً
- `npm start`

## النشر
انشر كخدمة Node Web Service على Render:
- Build command: `npm install`
- Start command: `npm start`
- Environment variable: `OWNER_TOKEN` (سرّ، لا تضعه في Git)
- يجب تفعيل HTTPS.

## الخصوصية
- لا يبدأ تحديد الموقع إلا بعد ضغط الزائر على زر المشاركة ومنحه إذن المتصفح.
- يمكن للزائر إيقاف المشاركة فوراً.
- تنتهي الجلسة بعد 30 دقيقة من آخر تحديث.
- تخزين الجلسات مؤقت داخل ذاكرة الخدمة فقط، ولا يوجد سجل تاريخي.
- رابط المالك يحتوي سراً في جزء الرابط (fragment) ولا يُرسل إلى الخادم في طلب HTTP. لا تشاركه مع أحد.
- إعادة تشغيل الخدمة تمسح الجلسات النشطة.
